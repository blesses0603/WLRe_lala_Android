# 飄流 RE:LaLa｜Android

**目前版本：v0.0.7** ｜ Android 12 以上 ｜ ARM64 手機測試版

## 🎮 主要功能

- **帳號與角色**：地球／水星伺服器、分流選擇、多帳號獨立登入、角色選擇、角色概況與狀態監控。
- **自動戰鬥與 AI**：角色／夥伴戰鬥規則、技能及普攻、自動徘徊、補給與自動操作狀態。
- **戰鬥與隊伍**：戰場資訊、手動戰鬥操作、陣形及隊伍管理。
- **地圖與移動**：小地圖、角色座標、移動、自動徘徊、場景與傳送功能。
- **物品與製作**：背包、技能、補品、煉金、製作配方、材料及製作排程。
- **社交與紀錄**：聊天、組織、事件紀錄、經驗效率及升級預估。
- **Android 專屬功能**：前景服務背景連線、常駐通知、Android Keystore 加密儲存帳密、懸浮小球。

## ✨ 新增項目（v0.0.7）

- **懸浮小球**：採用與 App 相同的 ICON，可拖曳、收合、隱藏，並顯示在線角色數。
- **懸浮角色概況**：展開後以科技風格卡片顯示角色／夥伴名稱、等級、HP／SP 數值與進度條，以及自動戰鬥、自動徘徊與事件狀態。
- **背景懸浮顯示**：使用者授予「顯示在其他應用程式上層」權限後，可在其他 App 上方查看角色概況；關閉小球不會主動中止遊戲連線。
- **Android Smoke 雙架構建置**：更新程式碼後自動建置 ARM64 手機 Debug APK 與 x86_64 模擬器 APK，並執行 Android 12～16 啟動測試。

## 🛠️ 修正與優化項目

- **角色概況同步**：主畫面與懸浮球共用狀態整理邏輯，降低等級、HP／SP 與 AI 狀態顯示不一致的機率。
- **斷線資訊**：離線帳號不再在懸浮面板顯示過期的角色詳細資料；帳號名稱以遮罩顯示。
- **聊天操作**：修正選擇聊天貼圖造成的閃退問題，改善中文輸入法輸入。
- **輸入文字顯示修正**：登入、密碼、聊天、搜尋和數值輸入框改用高對比淺色輸入底與深色文字，修正文字不清楚的問題；游標、提示文字及選取色同步調整。
- **主 App 全面圓角科技風**：統一深藍科技配色，重新繪製主要按鈕、帳號卡片、角色分頁、輸入框、下拉選項、核取圓鈕及設定彈窗；按下／停用狀態也能清楚辨識。
- **懸浮球資訊精簡**：不再顯示煉金、製作及補給，只保留角色／夥伴、HP／SP、戰鬥、徘徊和事件。主 App 角色概況保留完整資訊。
- **手機版面**：改善觸控卡片、文字易讀性與捲動排版。
- **APK 測試流程**：補強版本設定一致性檢查、SHA256 校驗；手機版本 Tag 建置與日常 Smoke 測試分開執行。

> 本專案仍屬 Android 開發測試版。以上為已整合功能，實際遊戲連線、自動操作及懸浮視窗仍以手機實測結果為準。
