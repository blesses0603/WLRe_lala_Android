# LaLa 全新重製計畫（Android 版）

> 文件性質：重製規劃與盤點基線，不代表新 APK 已實作、簽章或通過真機驗收。盤點基準：2026-10-27 的 `main`。

## 目標

從零建立 Android 新客戶端，與桌面版共用核心資料契約及業務規則，但保留 Android 原生生命週期、觸控互動、前景服務、Keystore 與懸浮球等平台整合。舊版僅作為行為、協定及安全機制參考。視覺採深藍科技風。

## 現況基線

- Repository：`blesses0603/WLRe_lala_Android`
- main 版本：`v0.0.8`；本次讀取 README 的 blob SHA：`63fe80160b57deadb09f290c762f40c26ef58b7e`
- 技術：Kivy／Python，Android 12+、ARM64；有共用 `wlre/core`、`wlre/network`、前景服務、Keystore、懸浮球與專屬 CI。
- README 說明此專案仍為開發測試版；正式伺服器操作與真機驗收須與 CI 分開確認。

## 重製原則

1. Android 以獨立 UI 與平台 adapter 呼叫共用核心，不將 Android 專屬 API 帶入 domain。
2. 不覆蓋舊版；新功能以獨立分支及 PR 階段交付。
3. 正確處理 Activity／App 前後景、程序被回收、服務生命週期、IPC 逾時及連線中斷。
4. 未確認的操作結果顯示未知，不假設成功、不自動重送可能重複消耗道具的指令。
5. 帳密不得寫入日誌或明文設定；沿用 Keystore 與建置簽章安全要求並重新審查。
6. 不更動 Android 版本號、不發布 APK 或 Tag，除非相應驗收完成。

## 目標模組

- `domain`／`application`：與桌面共用的模型、用例、狀態轉移與服務協調。
- `protocol`：共用封包編解碼、請求／回覆關聯與伺服器權威狀態。
- `android_adapter`：前景服務、IPC、Keystore、通知、權限與生命週期。
- `android_ui`：觸控優先的深藍科技風頁面、導航、狀態卡與操作確認。
- `tests`：共用契約、Android adapter 測試、打包／簽章檢查與真機驗收清單。

技術選型需透過 ADR 評估現有 Kivy、打包成本、原生整合與維護風險，再決定是否替換 UI toolkit。

## 分階段交付

### P0 — 盤點與桌面版對齊
- 建立 Android 功能清單，區分已實作、唯讀、停用、部分移植及待真機／正式服驗收。
- 對照 battle、map、accounts、items、expedition、social 的桌面／Android 行為與核心差異。
- 盤點 Android 權限、Keystore、簽章、IPC、前景服務、CI 與 APK 發布流程。

### P1 — 新架構骨架與 UI 設計系統
- 定義共用核心契約、Android adapter 介面、錯誤型別及命令生命週期。
- 建立深藍科技風設計 Token 與手機版導覽／觸控規範。
- 先交付不連正式伺服器的主框架、模擬資料及自動化測試。

### P2 — 帳號、連線與生命週期
- 多帳號資料隔離、登入／選角、前景／背景切換與連線狀態恢復。
- 驗證服務與 UI 的狀態同步、IPC 逾時、程序重建及資源釋放。
- 驗證 Keystore、日誌遮罩與 APK 依賴安全。

### P3 — Battle
- 建立手機版戰鬥資訊、手動操作與明確的執行／停止狀態。
- 接入已驗證的共用戰鬥用例；自動戰鬥須具備生命週期安全與停止條件。
- 以模擬器測試及真機測試分別記錄，不混為同一驗收。

### P4 — Map
- 小地圖、座標、場景切換、觸控移動及已驗證的傳點資料。
- 清楚區分本地畫面更新與伺服器確認；未知換圖結果不可假報成功。
- 驗證不同解析度、方向、字型、觸控命中區與捲動行為。

### P5 — Items 與其他功能
- 背包／道具、補給、製作、遠征、夥伴、社交及紀錄逐階段交付。
- 任何會消耗道具或改變伺服器狀態的操作，都要有資源預留、回覆驗證及逾時處理。

### P6 — APK 與驗收
- 執行單元／契約測試、Android CI、ARM64 APK 打包、簽章／雜湊檢查與真機安裝。
- 分開回報 CI、APK 安裝、背景服務及正式服 E2E 結果。
- 未通過必要驗收不建立正式 Release／Tag。

## 每階段完成條件

- 桌面／Android 共用核心契約一致，平台差異有明確 adapter。
- 權限、帳密、簽章與背景連線安全檢查通過。
- 變更有測試證據、回歸檢查及未完成項目說明。
- PR 標題使用繁體中文與版本格式；Android 版本號獨立管理。
