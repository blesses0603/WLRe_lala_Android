# LaLa Android：十張參考圖與實際 Kivy 功能頁對照

> 基準：使用者在本專案對話提供的十張「飄流 RE:LaLa」Android UI 參考圖。
> 稽核對象：Android `main` v7.1.15（commit `c6e68160568d2591c8265fedba5d9f2e559af76d`）。
> 這是**功能與資訊架構差異盤點**，不是宣稱圖片與已編譯 APK 一致；UI 顯示仍須真機截圖核對。

## 確認的根本差異

上一輪 PR #55 / #56 著重共用品牌標頭、霓虹卡片、圖示與操作外觀。原有 18 個獨立功能頁仍採既有資訊架構，**沒有**把參考圖中放在同一張畫面的多個功能全部整合：聊天/組隊、夥伴/能力、遠征/副本、煉金/製作、設定/NPC/儲藏/福利。

此外，參考圖中的帳號、HP、SP、座標、任務時間、官方版本及全部成功勾選僅為視覺範例，不可作為遊戲正式資料或支援功能證據。

|---|---|---|---|
| 1 官方資源驗證 | `verification_ui.py`、`verification_presentation.py`、`resource_sync.py` | 七項安全檢查、雙端登入閘門、版本／檢查狀態、重檢 | 真機尺寸與圖像比例仍待比對 |

## 後續實作順序（不新增假指令）

1. **P1（PR #57 已合併）**：夥伴出戰與角色能力的真實數值條、操作卡及離線降級；保留五屬性與安全閘門。
2. **P2（本次 v7.1.14 PR）**：小地圖本地縮放、角色定位、座標點選，以及背包/超空間袋的頁內真實物品詳情與操作前再次核對；尚未完成設計圖逐像素還原。
3. **P3（本次 v7.1.14 同版本追加）**：三組同頁整合操作，復用原頁和原伺服器指令；所有雙區塊可獨立展開與保留草稿。實機資訊密度與參考圖的逐元素對照尚未完成。
4. **P4**：工具中心集成 AI、NPC、儲藏、福利快捷入口與 320dp 手機可捲動的交互版面。
5. **逐頁驗收**：CI 契約與 Kivy 渲染測試 → ARM64 APK 編譯 → 真機 320dp/一般寬度截圖與觸控 → 正式服具體指令回覆；無實測不可宣稱通過。

**限制**：未取得官方相應角色肖像、忠誠/好友度上限、物品特殊效果、任意傳送協定或即時伺服器回覆前，只能顯示真實狀態／等待同步；不寫死設計圖的假資料。

## P2 驗收補充

- 對有官方原圖與投影的場景可縮放顯示及正確點選；沒有圖片或角色座標時維持只讀/等待狀態。
- 背包逐格預覽與遠端超空間袋唯讀共用安全驗證，不把選取操作視為伺服器已接受使用指令。
- 320dp Android 直式布局、實機截圖與 FPS 屬後續驗收，不因 CI 通過而宣稱完成。

## P3 驗收補充

- 原 18 頁仍可直接操作，新增 3 個整合入口（共 21 頁）；第二區塊初次展開才建立 Kivy 元件。
- 聊天及組隊共用當前帳號，同步聊天的 request_id 回覆仍需正確轉送。
- 遠征與副本只沿用已驗證流程，整合版副本預設不自動輪詢房間；煉金與製作不自動開始。
- 收合／展開不丟失草稿；實際真機效能與 320dp 佈局尚待量測。
