# 飄流 RE:LaLa｜Android

**目前版本：v0.0.7** ｜ Android 12 以上 ｜ ARM64 手機測試版

## 🎮 主要功能

- **帳號與角色**：地球／水星伺服器、分流選擇、多帳號獨立登入、角色選擇、角色概況與狀態監控。
- **自動戰鬥與 AI**：角色／夥伴戰鬥規則、技能及普攻、自動徘徊、補給與自動操作狀態。
- **戰鬥與隊伍**：戰場資訊、手動戰鬥操作、陣形及隊伍管理。
- **地圖與移動**：小地圖、角色座標、移動、自動徘徊、場景與傳送功能。
- **物品與製作**：24 格原始物品大圖示背包、道具詳情、超空間袋已驗證儲藏內容唯讀檢視、技能、補品、煉金、製作配方、材料及製作排程。
- **夥伴與遠征**：夥伴出戰／休息、官方 1262 遠征任務與獎勵、好友度補充、隊伍派遣及到期領獎（手動啟動）。
- **戰後修理／整理**：可設定修理耐久門檻、最多 2 種修理道具與 15 種整理道具；只使用已確認背包物品。
- **社交與紀錄**：聊天、組織、事件紀錄、經驗效率及升級預估。
- **Android 專屬功能**：前景服務背景連線、常駐通知、Android Keystore 加密儲存帳密、懸浮小球。

## ✨ 新增項目（v0.0.7）

- **同步桌面版共用核心**：移植遠征 S31、夥伴出戰 S19、戰後修理／整理、超空間袋 S62 唯讀協定及連線處理修正。
- **遠征頁面**：帳號／伺服器個別儲存派遣門檻、最低成功率、好友度及領獎設定；任務與獎勵採官方內建資料，不登入時不會自動派遣。
- **夥伴出戰頁面**：依伺服器資料檢視夥伴狀態與出戰／休息限制，按下後等待伺服器確認。
- **新版背包**：使用原始物品圖示，每頁 24 格，依手機寬度採四欄排版；可檢視道具資訊與切換清單模式，超空間袋未同步時不會顯示假內容。
- **原版功能 ICON**：以原版遊戲圖示新增可左右滑動的功能快捷列。
- **AI 修理／整理設定**：加入耐久門檻、修理道具與自動整理欄位，沿用核心不重送未確認操作的防護。
- **懸浮小球**：採用與 App 相同的 ICON，可拖曳、收合、隱藏，並顯示在線角色數。
- **懸浮角色概況**：展開後以科技風格卡片顯示角色／夥伴名稱、等級、HP／SP 數值與進度條，以及自動戰鬥、自動徘徊與事件狀態。
- **背景懸浮顯示**：使用者授予「顯示在其他應用程式上層」權限後，可在其他 App 上方查看角色概況；關閉小球不會主動中止遊戲連線。
- **Android ARM64 單架構建置**：主分支程式碼更新後自動建置 ARM64 手機 Debug APK，保留單元測試、簽章安全與 SHA256 檢查；不再啟動 API 31～36 模擬器測試。

## 🛠️ 修正與優化項目

- **Android 啟動畫面**：修正一直顯示 Kivy 預設黑底 `Loading...` 的問題，改為 LaLa 原 ICON 與深藍底色，並檢查編譯後 APK 確實包含自訂啟動畫面。
- **角色概況同步**：主畫面與懸浮球共用狀態整理邏輯，降低等級、HP／SP 與 AI 狀態顯示不一致的機率。
- **斷線資訊**：離線帳號不再在懸浮面板顯示過期的角色詳細資料；帳號名稱以遮罩顯示。
- **聊天操作**：修正選擇聊天貼圖造成的閃退問題，改善中文輸入法輸入。
- **輸入文字實際繪製修正**：修復圓角背景可能遮住 Kivy 輸入文字與提示文字的畫布層級問題；統一套用內建繁中字型，保留高對比配色與密碼遮罩，涵蓋帳號、密碼、聊天和搜尋欄位。
- **主 App 全面圓角科技風**：統一深藍科技配色，重新繪製主要按鈕、帳號卡片、角色分頁、輸入框、下拉選項、核取圓鈕及設定彈窗；按下／停用狀態也能清楚辨識。
- **懸浮球資訊精簡**：不再顯示煉金、製作及補給，只保留角色／夥伴、HP／SP、戰鬥、徘徊和事件。主 App 角色概況保留完整資訊。
- **手機版面**：改善觸控卡片、文字易讀性與捲動排版。
- **背景服務穩定性**：監控讀取失敗不再連帶結束所有遊戲連線；資源狀態以未知顯示。
- **IPC 指令可靠性**：失敗或逾時會釋放操作等待狀態、回報結果不明，不會擅自重送可能重複扣除道具的操作。
- **聊天訊息保護**：等待伺服器發話回應才清除輸入文字，拒絕、斷線或逾時均保留草稿。
- **桌面／手機功能對齊**：多帳號專用角色功能頁新增遠征及夥伴分頁，保留 Android 背景服務與懸浮小球，避免混入 Tkinter／Nuitka 桌面程式。
- **固定 APK 簽章支援**：三種建置共用 GitHub Secret 中的 Debug 金鑰（需先設定）；ZIP 另附簽章指紋，設定教學見 [簽名指南](ANDROID/SIGNING.md)。
- **APK 安全建置檢查**：建置前檢查私鑰、憑證及敏感設定；建置後檢查 APK 是否誤包金鑰。版本 Tag 必須使用固定簽章，詳見 [安全說明](ANDROID/SECURITY.md)。
- **前景 UI 恢復**：切離 App 後返回會重建 Kivy 主畫面並從既有服務同步帳號卡片；不重新登入或停止背景連線。歷史 Android 15／16 模擬器測試修正紀錄保留於驗證文件。
- **APK 測試流程**：保留版本一致性、SHA256 及安全檢查；版本 Tag APK 與日常 ARM64 手機測試 APK 分開建置。

> 本專案仍屬 Android 開發測試版。以上為已整合功能，實際遊戲連線、自動操作及懸浮視窗仍以手機實測結果為準。
