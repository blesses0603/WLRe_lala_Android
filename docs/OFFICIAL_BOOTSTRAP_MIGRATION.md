## 已遷移並從隨附種子實際移除的四項

| 舊內容 | 新來源與處理 |
| --- | --- |
| `server_list.json` | 每次正常官方準備流程依當前版本表取得 `ResourcesPC/ServerList.txt`，嚴格驗證後規範化匯入 SQLite；不再讀取種子或鬆散舊檔 |
| `default_profile.json` | 原本非憑證協定預設設定移為程式常數，語意與原受審核版本一致 |
| `enums.json` | 協定列舉移為程式常數；官方下載不得改變封包解碼規則 |
| `lala_supported_resources.json` | 發行版相容性政策移為程式常數；官方版本查詢可在完全沒有種子的情況下匯入與執行 |

已從 `bundled_active` 和 `bundled_resources` 同時刪除四項，VACUUM 移除空頁殘留；Manifest 與打包必要清單同步移除。種子驗證新增「不得含已遷移資料」檢查，並測試封裝清單不會重新帶入這四個檔名。既有使用者資料庫不做破壞性刪除，舊帳號與個人設定保留。

**仍有 23 項舊資源留在種子中，因此不是零離線遊戲資料版本。** 詳細剩餘來源與缺口沿用 [第一階段盤點](NORMALIZED_RESOURCE_DATABASE.md)：戰鬥／鍊金、圖集、導航幾何及剩餘 consumer 都還需要已驗證的新來源／adapter，不能只刪檔讓功能失效。

## 官方伺服器清單

預設來源改為使用者指定且已實測的 `wlreftpsrc.chinesegamer.net`；保留 `WLRE_OFFICIAL_RESOURCE_HOST` 在兩個已驗證官方主機之間選擇，不接受任意網址或跨主機轉址。

- 先查當前完整版本，再取同版 ServerList，之後再查版本，避免更新期間混用。
- HTTPS 回應限制 64 KiB／256 筆，要求唯一整數 ID、已存在群組、合法 Port 和目前實測的公開 IP 格式。未知 hostname／新格式拒絕；不推測格式。
- 清單並非 YooAsset Manifest 內的資產，其來源證據是受驗證 HTTPS 與版本前後一致；本機 SHA-256 用於完整性及版本識別，不假裝具有官方簽章。
- 成功後以交易切換 active 指標；原始 bytes、規範 snapshot 與舊版保留。失敗只記錄狀態，不覆蓋上一版。
- 離線首次啟動沒有清單，明確顯示需要更新；已成功匯入過則可顯示上一版及來源／時間。更新失敗會標示沿用舊清單。遊戲登入仍受原有版本閘門約束。
- 桌面登入介面重新讀取清單；Android 在同步狀態變更後刷新選單。若舊分流消失，Android 要求重新選擇，不替使用者改選後送出已輸入帳號。
- 原本自訂連線與已保存帳號不因清單未下載而被刪除；同群組帳號設定與舊設定遷移已有測試。

2026-11-05 已實際從官方 `1.3.23/ResourcesPC/ServerList.txt` 成功取得、驗證、匯入並讀回 7 個分流。此測試未連線任一遊戲 IP，沒有登入或送出遊戲封包。

## 發佈依賴與限制

Android 不在 Git 追蹤 seed binary，仍由 `ANDROID/DESKTOP_SOURCE_LOCK.json` 指定桌面來源 commit、大小與 SHA-256。第二階段必須先讓桌面縮減後種子所在 commit 可取得，再發布對應 Android 指紋；不能讓 Android 繼續下載舊 27 項種子卻宣稱遷移完成。

本階段不更改應用版本、main 或 Release。官方完整資料替換、手機／原生安裝包、正式服登入及人工驗收仍未完成。
