# 飄流 RE:LaLa｜Android

**目前版本：v0.0.8** ｜ Android 12 以上 ｜ ARM64 手機測試版

## 🎮 主要功能

- **帳號與角色**：地球／水星伺服器、分流選擇、多帳號獨立登入、角色選擇、角色概況與狀態監控。
- **自動戰鬥與 AI**：角色／夥伴戰鬥規則、技能及普攻、自動徘徊、補給與自動操作狀態。
- **戰鬥與隊伍**：戰場資訊、手動戰鬥操作、陣形及隊伍管理。
- **地圖與移動**：小地圖、角色座標、移動、自動徘徊、場景與傳送功能。
- **物品與製作**：24 格原始物品大圖示背包、道具詳情、超空間袋已驗證儲藏內容唯讀檢視、技能、補品、煉金、製作配方、材料及製作排程。
- **夥伴與遠征**：夥伴出戰／休息、官方 1262 遠征任務與獎勵、好友度補充、隊伍派遣及到期領獎（手動啟動）。
- **戰後修理／整理**：可設定修理耐久門檻、最多 2 種修理道具與 15 種整理道具；只使用已確認背包物品。
- **社交與紀錄**：聊天、組織、事件紀錄、經驗效率及升級預估。
- **Android 專屬功能**：前景服務背景連線、常駐通知、Android Keystore 加密儲存帳密、懸浮小球。

## ✨ 新增項目（v0.0.7，保留）

- **同步桌面版共用核心**：移植遠征 S31、夥伴出戰 S19、戰後修理／整理、超空間袋 S62 唯讀協定及連線處理修正。
- **遠征頁面**：帳號／伺服器個別儲存派遣門檻、最低成功率、好友度及領獎設定；任務與獎勵採官方內建資料，不登入時不會自動派遣。
- **夥伴出戰頁面**：依伺服器資料檢視夥伴狀態與出戰／休息限制，按下後等待伺服器確認。
- **新版背包**：使用原始物品圖示，每頁 24 格，依手機寬度採四欄排版；可檢視道具資訊與切換清單模式，超空間袋未同步時不會顯示假內容。
- **原版功能 ICON**：以原版遊戲圖示新增可左右滑動的功能快捷列。
- **AI 修理／整理設定**：加入耐久門檻、修理道具與自動整理欄位，沿用核心不重送未確認操作的防護。
- **懸浮小球**：採用與 App 相同的 ICON，可拖曳、收合、隱藏，並顯示在線角色數。
- **懸浮角色概況**：展開後以科技風格卡片顯示角色／夥伴名稱、等級、HP／SP 數值與進度條，以及自動戰鬥、自動徘徊與事件狀態。
- **背景懸浮顯示**：使用者授予「顯示在其他應用程式上層」權限後，可在其他 App 上方查看角色概況；關閉小球不會主動中止遊戲連線。
- **Android ARM64 省額度 CI**：PR 與主分支更新只執行 Python 回歸、安全與版本檢查；完整 ARM64 APK 改成在 main 手動啟動或符合版本的 Tag 才編譯，仍保留固定簽章、SHA256 與封裝安全驗證。

## ✨ 新增項目（v0.0.8）

- **Android ARM64 Cython 原生封包核心**：正式 ARM64 APK 打包以隔離 staging 編譯 `wlre/network/wire.py` 為 `_wlre_wire_native.so`，應用程式僅保存匯入 shim。保留 API 與封包行為，Cython 提高靜態還原成本但並非不可逆向。
- **既有固定簽章**：正式 Buildozer 完成後，沿用 Secret 還原的 Debug 簽章憑證、公開 SHA256 pin、APK 重簽及檢查，支援相同套件名稱的版本升級驗收。
- **原生安全驗收門檻**：實際 APK 必須在 `libpybundle.so` 含 ARM64 ELF、只保留符合預期的 `wire.pyc` shim，並上傳原生驗證、簽章與 SHA256 報告，否則阻止 Artifact 發布。

## 🛠️ 修正與優化項目

- **Android 啟動畫面**：修正一直顯示 Kivy 預設黑底 `Loading...` 的問題，改為 LaLa 原 ICON 與深藍底色，並檢查編譯後 APK 確實包含自訂啟動畫面。
- **角色概況同步**：主畫面與懸浮球共用狀態整理邏輯，降低等級、HP／SP 與 AI 狀態顯示不一致的機率。
- **斷線資訊**：離線帳號不再在懸浮面板顯示過期的角色詳細資料；帳號名稱以遮罩顯示。
- **聊天操作**：修正選擇聊天貼圖造成的閃退問題，改善中文輸入法輸入。
- **輸入文字實際繪製修正**：修復圓角背景可能遮住 Kivy 輸入文字與提示文字的畫布層級問題；統一套用內建繁中字型，保留高對比配色與密碼遮罩，涵蓋帳號、密碼、聊天和搜尋欄位。
- **主 App 全面圓角科技風**：統一深藍科技配色，重新繪製主要按鈕、帳號卡片、角色分頁、輸入框、下拉選項、核取圓鈕及設定彈窗；按下／停用狀態也能清楚辨識。
- **懸浮球資訊精簡**：不再顯示煉金、製作及補給，只保留角色／夥伴、HP／SP、戰鬥、徘徊和事件。主 App 角色概況保留完整資訊。
- **手機版面**：改善觸控卡片、文字易讀性與捲動排版。
- **背景服務穩定性**：監控讀取失敗不再連帶結束所有遊戲連線；資源狀態以未知顯示。
- **IPC 指令可靠性**：失敗或逾時會釋放操作等待狀態、回報結果不明，不會擅自重送可能重複扣除道具的操作。
- **聊天訊息保護**：等待伺服器發話回應才清除輸入文字，拒絕、斷線或逾時均保留草稿。
- **桌面／手機功能對齊**：多帳號專用角色功能頁新增遠征及夥伴分頁，保留 Android 背景服務與懸浮小球，避免混入 Tkinter／Nuitka 桌面程式。
- **固定 APK 簽章支援**：手動／Tag 完整建置沿用既有 GitHub Secret Debug 金鑰與公開 SHA256 指紋鎖定；快速 CI 不取得簽章 Secret。ZIP 另附簽章報告，見 [簽名指南](ANDROID/SIGNING.md)。
- **APK 安全建置檢查**：建置前檢查私鑰、憑證及敏感設定；建置後檢查 APK 是否誤包金鑰。版本 Tag 必須使用固定簽章，詳見 [安全說明](ANDROID/SECURITY.md)。
- **前景 UI 恢復**：切離 App 後返回會重建 Kivy 主畫面並從既有服務同步帳號卡片；不重新登入或停止背景連線。歷史 Android 15／16 模擬器測試修正紀錄保留於驗證文件。
- **APK 測試流程**：日常 [快速 Actions](.github/workflows/android-smoke.yml) 不產生 APK；需手機安裝包時使用 [手動／版本 Tag Actions](.github/workflows/android-apk.yml)，保留 SHA256、固定簽章及安全檢查。[操作說明](ANDROID/README.md#github-actions節省額度的兩階段模式2026-10-19)。

> 本專案仍屬 Android 開發測試版。以上為已整合功能，實際遊戲連線、自動操作及懸浮視窗仍以手機實測結果為準。

## 🧭 桌面 v0.5.6 對齊進度（分階段）

本次新增「副本資料」官方 1262 本機唯讀目錄，以及「角色能力」已同步數值的唯讀檢視。副本建立／加入／領獎、角色配點與新事件核心仍**未移植**；不會在這兩個頁面送出任何遊戲封包。詳細範圍見 [同步紀錄](ANDROID/DESKTOP_SYNC_20261020.md)。Android 版本與正式簽章／APK 建置方式暫不變。


### 第二批電腦版同步（v0.5.6，開發分支）

Android 副本功能支援 **手動向伺服器查詢房間清單**（S85／S186），並可檢視實際已回覆的房間資料。手機版尚不能建立、加入、準備、開始、領獎或配點；不要將唯讀畫面解讀為可進行副本操作。加入 S51-1 異常長度容錯及安全診斷，正式伺服器與手機實測仍待完成。


### 第三批桌面 v0.5.6 同步（跨服務安全）

Android 新增登入／世界／戰鬥狀態事件路由、戰後維護和場外補給的共用格位預留，以及自動煉金、製作、遠征和徘徊之間的暫停協調。未知補給結果禁止自動恢復，未確認的物品格位維持鎖定；網路佇列的異常指令也增加安全驗證。其他舊式保留計數、簽章 APK 編譯與手機實測仍需後續處理，版本暫維持 `0.0.8`。


### 第四批 Android 核心跟進（v0.5.6）

戰鬥耗材、煉金材料及遠征好友度恢復已改採共用格位與序號預留。修正 S31-15／S31-19 與官方 1262 封包結構的差異，增設領獎後伺服器任務刷新及斷線保留狀態測試。舊帳號的未確認請求不會被當成成功或自動重送。APK 簽章、版本 `0.0.8` 與 Android 平台核心仍保留；正式伺服器與手機驗收尚待進行。


### 第五批：Android 製作材料安全整合（2026-10-21）

修正製作排程在扣料前未預留格位的問題。製作新增材料身分、數量、序號的共用預留；手動／自訂清單皆套用跨服務衝突閘門。排程回覆與材料扣除須雙重確認；逾時與斷線的未知操作不重送、不解除鎖定。新增 10 項專項回歸測試；保留原有等待狀態提示。Android 版本維持 `0.0.8`，正式伺服器操作及手機驗收仍待進行。
